Project Page Writeup Code

Project Page Code

Assorted class projects for EECS 367 at UMich, including A* search, forward & inverse kinematics, and RRT planning.

Interactive Piano Lights (2020)

Project Page Code
Particle-Based Localization and Grasping of Grocery Bags (2018-2019)
Detecting handles of a paper grocery bag in video feed and triangulating 3D locations with a particle filter for robot grasping.
