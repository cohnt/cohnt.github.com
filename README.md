# Thomas Cohn - Personal Website

Personal website for **Thomas Cohn**, Computer Science PhD Candidate in the Robot Locomotion Group at MIT CSAIL, advised by Professor Russ Tedrake.

**Website URL:** [https://tommycohn.com](https://tommycohn.com)

---

## Overview

This repository contains the source code for Thomas Cohn's personal academic website. The site highlights research, publications, news, course notes, and video demonstrations focused on robotic manipulation, motion planning, optimization, and kinematics.

### Key Sections
- **About Me**: Background, research interests in robotic manipulation, kinematics, optimization, and learning.
- **Recent News**: Updates on conference presentations, paper acceptances, awards, invited talks, and media features.
- **Featured & Complete Publications**: Complete directory of research papers with links to preprints, posters, project pages, source code, and BibTeX entries.
- **Featured Videos**: Demonstrations of constrained bimanual planning and motion planning algorithms.
- **Course Notes**: Open LaTeX notes for advanced mathematics and computer science courses.

---

## Technologies Used

- **HTML5 & CSS3**: Custom responsive layout with vanilla CSS tokens, glassmorphism elements, and smooth interactions.
- **JavaScript (ES6+)**: Interactive UI controls (scroll toggles, bibtex expansion, publication filtering).
- **Icons**: [Font Awesome 6](https://fontawesome.com/) & [Academicons](https://jpswalsh.github.io/academicons/).
